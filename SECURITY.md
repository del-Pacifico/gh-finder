# 🕶️ gh-finder – Security Policy

## Supported Versions

gh-finder is currently in MVP development. Security fixes are applied to the latest release only.

| Version | Supported |
|---|---|
| 0.1.x | ✅ |
| < 0.1.0 | ❌ |

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

To report a security vulnerability, use GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/del-Pacifico/gh-finder/security) of this repository.
2. Click **"Report a vulnerability"**.
3. Provide a description of the issue, including:
   - Affected version
   - Steps to reproduce
   - Potential impact
   - Any proof-of-concept (if applicable)

### What to expect

- We aim to acknowledge reports within **5 business days**.
- We will investigate and keep you informed of progress.
- If the vulnerability is confirmed, we will coordinate a disclosure date with you and credit you (unless you prefer to remain anonymous).
- We will release a fix as soon as reasonably possible.

## Scope

This policy covers the `gh-finder` Python package and its command-line interface. It does not cover:

- GitHub's API or infrastructure (report those to GitHub directly).
- Third-party dependencies (report those to the respective maintainers).

## Thank You

We appreciate responsible disclosure and thank everyone who helps keep gh-finder safe.
